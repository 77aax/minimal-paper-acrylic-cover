# 插画提示词骨架与标题示例

## 通用骨架（图生图，参考图=原照片，输出 1080×720）

```
极简纸感丙烯插画。纯背景为带细微颗粒的粗糙奶油暖米白纸，无任何文字。
画面中央画一个小小主体，仅占画面15-20%，四周大量留白。
用轻微不稳的纤细黑色手绘线条勾勒轮廓，叠加少量丙烯平涂色块，
色块保留手工涂抹的不规则毛边。
主体：〔一句话描述原片核心主体/场景轮廓姿态，舍弃细节〕。
颜色取自参考照片，主色不超过4种。仅极简暗示环境。
艺术书绘本质感，安静诗意。
禁止写实、照片复刻、主体过大、3D渲染、水彩晕染、纯线稿、过多色彩、文字、水印、边框。
```

要点：
- 插画**不要带任何文字**，文字由 compose.py 后期排版。
- 只提炼核心主体（人/动物/建筑/山/树/河），环境用一两笔极简暗示。
- 颜色直接照搬照片主色，控制在 ≤4 色。
