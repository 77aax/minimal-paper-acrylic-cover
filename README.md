# minimal-paper-acrylic-cover

把一张旅行/风景照片转成「极简纸感丙烯封面」：上半原照片，下半奶油米白纸底上的小幅手绘丙烯插画，配疏朗中英短句，艺术书/绘本质感。

## 效果
- 竖图（port）：完整不裁切照片居中偏上 + 下方小插画
- 横图（land）：满宽照片带贴顶 + 下方柔化小插画，不硬拼接

## 文件
- `SKILL.md` — 给 AI Agent 的完整工作流与风格规范
- `scripts/compose.py` — 确定性合成脚本（照片+插画→1080×1440 成品）
- `references/prompt.md` — 生成插画用的提示词骨架与标题示例

## 用法（给 AI）
把本目录放进你的 skills 目录，然后对它说「把这张照片做成纸感丙烯封面」即可。
